# 🎬 Movie Genre Prediction from Plot Summaries

This project builds a machine learning pipeline to predict movie genres based on plot summaries using Natural Language Processing (NLP) techniques and supervised learning models. It demonstrates an end-to-end text classification workflow from raw text data to genre prediction.

## Project Highlights
- End-to-end NLP and machine learning pipeline
- Text preprocessing and feature extraction
- Genre classification using supervised ML models
- Model evaluation using standard classification metrics

## Dataset
- Type: Text-based dataset containing movie plot summaries
- Input: Movie plot descriptions
- Output: Movie genre labels

## Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- NLP techniques (text cleaning, tokenization)
- TF-IDF vectorization

## Workflow
1. Load and explore movie plot summary dataset
2. Text preprocessing (lowercasing, punctuation removal, stopword removal)
3. Feature extraction using TF-IDF
4. Model training (Logistic Regression / Naive Bayes)
5. Model evaluation (Accuracy, Precision, Recall, F1-Score)
6. Genre prediction on unseen data

## Results
- Successfully classified movie genres based on plot summaries
- Demonstrated effectiveness of NLP-based feature extraction
- Built a complete text classification pipeline
